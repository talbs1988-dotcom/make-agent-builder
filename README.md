# make-agent-builder

סקיל ל-Claude Code שבונה סוכני AI ואוטומציות ב-Make.com — מהאפיון מול בעל העסק ועד תרחיש שרץ.

נבנה על ידי [טל בשור](https://tal-b.com) מתוך בנייה אמיתית של סוכן ניהול לידים בוואטסאפ עסקי רשמי, כולל כל התקלות שעלו בדרך.

## מה הוא עושה

**מאפיין.** מריץ ראיון מונחה עם בעל העסק — לא שאלה פתוחה שמשאירה אותו בהתה, אלא רשימה שהוא מזהה מהיום-יום שלו ומסמן. כל פעולה שסימן מתורגמת לטבלה של ארבע עמודות: מה שביקשת · הכלי שהוא צריך · המידע שהכלי צריך · מה יקרה בלי זה.

**מתעד.** מפיק מסמך ארכיטקטורה ב-15 סעיפים — מודולים, מיפויים, תנאים, טיפול בשגיאות, סיכונים ותוכנית בנייה.

**בונה.** אם Claude Code מחובר ל-Make דרך MCP, הוא בונה את התרחיש ישירות בחשבון שלך. אם לא — הוא מפיק בלופרינט לייבוא.

## הכלל שהסקיל בנוי סביבו

> פעולה שאין לה כלי ואין לה מידע היא לא יכולת של הסוכן. היא סיפור שהוא יספר ללקוח שלך.

סוכן שכתוב לו "בדוק ביומן ותציע שעות פנויות" ואין לו כלי לקרוא יומן — לא יגיד לך שהוא לא יכול. הוא ימציא שעות. סוכן שכתוב לו "שלח מייל לצוות" ואין לו כלי מייל — יגיד ללקוח שהעביר, ולא יעביר.

הסקיל מוודא שלכל הנחיה יש כלי אמיתי מאחוריה.

## התקנה

```bash
git clone https://github.com/talbs1988-dotcom/make-agent-builder.git ~/.claude/skills/make-agent-builder
```

זהו. פותחים Claude Code ואומרים לו **"תבנה לי סוכן ב-Make"** או **"תנתח לי את התרחיש"**, והוא נטען לבד.

להתקנה ידנית: מורידים את הקבצים ושמים אותם ב-`~/.claude/skills/make-agent-builder/` באותו מבנה.

## מה יש בפנים

| הקובץ | מה יש בו |
| --- | --- |
| `SKILL.md` | תהליך העבודה: אפיון, שלוש שכבות ההנחיה, חמש משפחות הכלים, בנייה ובדיקה |
| `references/architecture-format.md` | מסמך הארכיטקטורה ב-15 סעיפים, וחמש השכבות שהוא חייב לכסות |
| `references/make-gotchas.md` | המלכודות של Make — כולן עלו בבנייה אמיתית ועלו זמן |

## למה `make-gotchas.md` הוא החלק החשוב

ההבדל בין תרחיש שנוצר לתרחיש שרץ הוא בפרטים שאף מדריך לא מספר עליהם. כמה מהם:

- מודול היומן במצב `detail` דורש שני שדות חובה שלא מופיעים בטופס. בלעדיהם התרחיש נפסל באימות
- `limit` שנכתב כמחרוזת ולא כמספר מפיל את כל התרחיש
- webhook שייך לתרחיש אחד בלבד. אי אפשר לחלוק אותו בין שניים
- מספר הטלפון שמגיע מוואטסאפ כבר כולל קידומת. הוספת קידומת עוד פעם והודעה לא מגיעה
- שדה בחירה ריק ב-Airtable יפיל כתיבה, אלא אם פותחים `typecast`

בסקיל יש רשימה מלאה, ולכל מלכודת גם התיקון.
